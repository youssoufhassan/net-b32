# net-b32
Le projet net-b32 est le jeu "Net" en texte.

## Authors
Les auteurs sont : 
    - Hassan Youssouf Youssouf
    - Anthony De Jesus
    - Matéo Wache


## Description
Net est un jeu de logique avec un puzzle. Le joueur doit tourner les différentes pièces du puzzle de façon à ce qu'elles soient toutes reliées
entre elles. Pour cela il peut donc les tourner dans le sens horaire ou anti-horaire, il peut aussi défaire et refaire ses dernières actions. 
Lorsque le joueur lance le jeu, le puzzle est affiché et il peut commencer à jouer. A chaque action le puzzle est affiché de nouveau.

## Langage
Le jeu est programmé entièrement en C.
